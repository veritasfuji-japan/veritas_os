# Promotionに結び付けた人間承認の発行

`veritas_os.policy.gate_bound_human_approval_issuance` の
`issue_promotion_gate_bound_human_approval_artifact`に、replayレビュー、
runtime riskレビュー、完全な最終credential-scopeソース、信頼できるaction contract、
実際の人間の判断イベント、配備環境が管理する署名器、タイムゾーン付き現在時刻`now`を渡します。
一時鍵の生成はテスト内だけです。APIは鍵を保存せず、人間の判断も作成しません。
呼び出し元が認証と署名者ポリシーを管理します。

ソースを独立検証し、承認時刻がreplayレビュー以降であること、署名時刻が承認以降かつ
未来ではないこと、失効時刻が現在より後かつrisk/replay期限以内であることを確認します。
不正入力は署名前に拒否します。既存のレシート構築処理で実行対象、スコープ、承認者ID・
ロールを照合します。拒否などの非承認結果を承認に変換しません。

既存v1署名付きレシート形式を維持します。予約済みmetadata
`promotion_approval_binding`にレビューのハッシュ、ソース射影、最終エンドポイント・
資格情報スコープのダイジェスト、intent、adapter、Bind contextを格納し、署名対象にします。
呼び出し元による予約領域の上書きは禁止です。それ以外の任意metadataは認可判断に使いません。

戻り値は署名付き成果物であり、検証済みレシートや実行許可ではありません。
次段では既存の信頼済み人間承認検証器とcontext照合を使用します。
Promotion側の後続処理では、署名されたPromotion来歴も独立検証した現在のソースと
照合する必要があります。自動ランタイム統合、資格情報取得、消費、送信、Bind実行は追加しません。
権限検証、失効確認、最終ランタイム再確認も引き続き必要です。
