# NeoMundi RGC v0.2 Real-Observation PoC Runbook

## Purpose

This runbook defines the first real NeoMundi → VERITAS external measurement proof.

The PoC verifies one real NeoMundi-generated signed RGC v0.2 observation, seals it behind the existing provider-neutral `ExternalMeasurementEvidence` boundary, and emits reproducible verification artifacts.

It does not create execution authority.

## Boundary

The following invariants remain mandatory:

```text
Measurement != Authority
Advisory != Authorization
Signal Verification != Execution Permission
Within Bounds != VERITAS ALLOW
External Evidence != Governance Decision
```

A successful run proves only that VERITAS independently accepted one signed measurement artifact under an explicit VERITAS-controlled trust policy.

It does not prove production readiness, certification, a customer deployment, or permission to execute an external action.

## Required Intake From NeoMundi

For the first real observation, obtain:

1. One real RGC v0.2 JSON artifact generated by NeoMundi.
2. The public JWKS that contains the Ed25519 key referenced by `integrity.key_id`.
3. A stable signer identity in `integrity.signer_identity`.
4. `identity.schema_version = 0.2.0`.
5. A timezone-aware `identity.timestamp`.
6. The measurement and normalizer versions in `provenance`.
7. The expected RGC v0.2 governance boundary with:
   - `authorization_status = not_applicable`
   - `execution_permission_changed = false`

Do not request a private signing key. VERITAS needs public verification material only.

## Runner

The repository provides:

```text
scripts/run_neomundi_real_observation_poc.py
```

The runner composes:

```text
real RGC v0.2 artifact
+ operator-supplied trusted public JWKS
        ↓
NeoMundiRgcV02Verifier
        ↓
provider verification result
        ↓
ExternalMeasurementTrustPolicy
        ↓
replay-safe generic ExternalMeasurementEvidence boundary
        ↓
VerifiedExternalMeasurementEvidence
        ↓
verification report + evidence manifest
```

No network JWKS lookup is performed.

## Example

```bash
python scripts/run_neomundi_real_observation_poc.py \
  --artifact /secure/inbox/neomundi-rgc-v0.2.json \
  --jwks /secure/inbox/neomundi-public-jwks.json \
  --replay-state-dir .veritas-poc/neomundi-replay-state \
  --output-dir evidence/neomundi/real-observation-001 \
  --max-age-seconds 3600 \
  --max-future-skew-seconds 60 \
  --allow-no-expiry
```

`--allow-no-expiry` is intentionally explicit. NeoMundi RGC v0.2 does not currently provide an `expires_at` field, while the generic VERITAS evidence boundary requires expiry by default.

For a reproducible review run, `--now` may be supplied with a timezone-aware ISO-8601 value:

```bash
--now 2026-09-11T06:00:00+00:00
```

Do not use an arbitrary historical `--now` value to make stale evidence appear fresh. Any review artifact must record the actual validation context.

## Durable Replay State

`--replay-state-dir` is required.

The PoC runner creates one durable local marker for each accepted replay key using exclusive file creation. Re-running the same accepted artifact against the same replay-state directory fails with:

```text
external_measurement_replay_detected
```

This local filesystem mechanism is sufficient for the reproducible PoC but is not a distributed production replay service and must not be described as one.

## Outputs

A successful run writes:

```text
verification_report.json
verified_external_measurement_evidence.json
evidence_manifest.json
```

### verification_report.json

Records:

- provider verification result
- verifier identity and policy binding
- generic trust-policy acceptance
- freshness policy
- explicit no-expiry posture
- claim boundary

### verified_external_measurement_evidence.json

Contains the sealed provider-neutral `VerifiedExternalMeasurementEvidence` representation, including:

- normalized evidence
- evidence hash
- key ID and algorithm
- verifier policy hash
- trust policy hash
- replay key
- verification proof hash

### evidence_manifest.json

Binds the run to:

- provider and artifact ID
- RGC artifact version
- payload hash
- canonical artifact hash
- exact input-file SHA-256 when invoked through the CLI
- canonical and exact-file JWKS hashes
- verifier policy
- trust policy
- evidence hash
- verification proof hash
- output canonical hashes

The manifest also records explicit non-claims.

## Failure Behavior

The runner fails closed.

Provider-specific failures preserve the deterministic NeoMundi reason when available, for example:

```text
neomundi_rgc_payload_hash_mismatch
neomundi_rgc_key_untrusted
neomundi_rgc_signature_invalid
neomundi_rgc_execution_permission_invalid
```

Generic boundary failures remain generic VERITAS evidence failures, for example:

```text
external_measurement_stale
external_measurement_expiry_missing
external_measurement_replay_detected
external_measurement_verifier_binding_mismatch
```

On failure, the CLI writes `verification_report.json` but does not emit a successful sealed-evidence file or success manifest.

## First Real PoC Exit Criteria

The NeoMundi external proof is not closed until all of the following are true:

1. The input is a real NeoMundi-generated signed RGC v0.2 artifact, not a repository fixture.
2. VERITAS independently verifies payload identity, key binding, JWS signature, signed claims, semantics, and freshness.
3. Replay protection accepts the artifact only once in the selected PoC replay-state namespace.
4. A `VerifiedExternalMeasurementEvidence` proof is produced.
5. Measurement remains structurally separate from AuthorityEvidence, HumanApproval, and BindAuthorization.
6. VERITAS governance inputs are evaluated independently after the measurement verification step.
7. The later governance result is bound into an auditable receipt / Evidence Packet.
8. The complete run is reproducible and reviewable from preserved artifacts.

## Current Scope

This runner intentionally stops before VERITAS Policy / Authority / Human Approval evaluation.

That separation is deliberate. The first step is to prove that real third-party measurement can cross the verification boundary without becoming authorization. The subsequent PoC step may consume the resulting verified measurement as evidence while VERITAS makes its own governance decision.

## Non-Goals

This work does not change:

- native v2 authorization
- credential resolution
- Bind execution
- external-effect semantics
- BindReceipt / Outcome semantics
- reconciliation
- crash recovery
- frozen Decision-to-Effect architecture
- RCC / REVAS behavior

It also does not include any real NeoMundi observation or key material in the repository.
